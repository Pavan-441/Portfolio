To-DO List using Node JS

This project is a simple full-stack to-do list web application that enables users to manage their daily tasks. It is built using Node.js, Express, and MySQL for backend operations, and a clean Bootstrap-based frontend for UI interaction. Users can add new tasks, update existing ones, or delete completed tasks. The application demonstrates the use of RESTful APIs and live data manipulation using JavaScript Fetch API. It also showcases MySQL integration for persistent storage and includes real-time task rendering without page refresh. This project helped me reinforce CRUD operations, client-server communication, and frontend/backend integration in a Node.js environment.
